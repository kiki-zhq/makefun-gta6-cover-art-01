Vice Cover Studio turns your own photos into GTA-style cover art: pick a multi-panel layout, drop in up to three photos, crop and position each panel (sliders, drag on the preview, or arrow keys), write a bold poster caption, choose a Vice Sunset, Neon Night or Gold Hour colour grade, and export a PNG at 1080 × 1080, 1080 × 1350 or 1920 × 1080 — all offline, in plain static HTML, CSS and JavaScript, with no network requests and no Rockstar artwork, logos or fonts.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Upload photos (or tap a sample), pick a layout, edit the caption, and export.
